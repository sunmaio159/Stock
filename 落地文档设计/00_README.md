## 核心口径（违反即返工）

1. 情绪指数 **[0,100]**，中性 50，无数据 `NULL`；公式见 04 §3
2. 评分卡权重 **25/20/20/20/15**，只存 `ana_factor_def`（**V3 建表，不在当前 31 表 DDL 内**）
3. 全系统 **Asia/Shanghai + 交易日历**（禁 `MON-FRI`/`minusDays(1)`）
4. 表结构以 02 §四 为准（**内联全量 DDL，无外键，逻辑关联+应用层一致性**）；API 以 03 §三 为准
5. V1 **单机单实例**，规模 ≤100 用户 / 50 并发；范围以 06 §范围守门 + 01 §五 边界声明为准，禁加 V2 功能
6. **数据源可配置插件模式**（02 §二）：舆情 = 东财/雪球/同花顺，行情 = 东财/腾讯/新浪（互备自动切换）；新增源优先走通用 Adapter 纯配置接入
