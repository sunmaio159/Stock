### 标注规范（V1.3 新增，OPS-08）

《情感标注手册》核心定义：
- **positive**：明确看好、推荐、利好描述
- **negative**：明确看空、警告、利空描述
- **neutral**：客观陈述无褒贬、问句、转发无评论
- **歧义处理**："提及风险但结论正面"→ 按结论（positive）；"反讽/阴阳怪气"→ 标注者讨论后仲裁
- 双人独立标注 → 计算 Cohen's Kappa → Kappa ≥ 0.7 后作为验收基线

## 5. 工程质量看板与双周门禁（V1.3 新增，C-05）

（内容同 05 §5.7，此处列入口）

### 可观测性优先原则（W0 出口条件）
`crawl_task_total` / `pipeline_queue_size` / `api_latency` 三个指标在 W1 结束前必须可见，否则不允许进入 W2 功能开发。

### 双周工程门禁
未过则当周不加新功能：采集成功率 72h ≥99% / 词典回归准确率不降 >3pp / 去重命中率 5%-40% / 详情页 P95 ≤800ms / 告警噪音率 ≤30% / 任务回放通过 / 死信清空+对账 diff ≤0.1%
