### W0.4 数据源长样本验证方案（3 日探针 · 硬性一票否决门禁）

> **纪律条款**：本验证是 V1 唯一的硬门禁。探针脚本**独立于主工程**（独立 main 函数/独立目录，不 import 主工程代码，防止为通过验证而污染正式实现）。**未出探针报告前，W1 不得开工**；任何人不得以"接口能通"为由跳过。

短样本（30min 抓通）只能证明"接口存在"，证明不了"能长期稳定采"。W0 用最小探针脚本对五源做 3 天长样本验证：

| 源 | 探针动作 | 采样方式 | 通过标准 |
|---|---|---|---|
| 东财股吧 | 抓取 10 只高/中/低活跃股吧列表+详情 | 每 30min 一次 × 3 天（~144 轮） | 成功率 ≥99%；字段完整率（标题/作者/时间/互动）≥98%；HTTP 200 中无验证码页特征 |
| 雪球 | 同上（需 Cookie 有效性验证） | 同上 | 成功率 ≥97%；Cookie 3 天内不失效（或可程序续期） |
| 同花顺 | 股吧列表 HTML 解析 | 同上 | 成功率 ≥95%；选择器命中完整率 ≥95% |
| 腾讯行情 | qt.gtimg 批量快照（100 代码） | 每 1min × 盘中 3 天 | 成功率 ≥99.5%；数据与东财交叉偏差 ≤0.5% |
| 新浪行情 | hq.sinajs 同上（注意 GBK 编码） | 同上 | 同上 |

**产出**：每源一份探针报告（成功率曲线/字段完整率/延迟分布/封禁迹象），落入 `sys_audit_log` 式的验证记录文件，作为 W2  Adapter 开发的输入与 SLA 基线。
**判据**：舆情主源（东财）+ 行情至少一源过线 → GO；东财不过但雪球/同花顺过 → 降级方案 GO（主源切换，排期 +3 天）；舆情三源全不过 → 停线重评。

## 范围守门（强制执行）

1. 任何需求进迭代前过三问：V1 必要吗？不做影响核心价值吗？能留 V2 吗？
2. 滑期砍单顺序：雪球/同花顺降为东财单源 → 告警仅站内 → 词云降级 Top 词表
3. 双周工程门禁：采集成功率 / 热帖延迟 / 指数 NULL 占比 / 告警触达率 / 死信积压，五项不达标停新功能
4. **W2/W3 各 20% 缓冲为锁死资源**：只可用于反爬对抗（W2）与词典调优（W3）的意外工时，**禁止挪作新功能**；周末前缓冲未用完→提前进入下周任务，不临时加需求
