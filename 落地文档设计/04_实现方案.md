### 1.2 调度器（扫描/执行分离，定稿骨架）

```java
@Component
public class CrawlScheduler {
    private final ThreadPoolTaskScheduler scanner;   // poolSize=1, 仅扫描分发
    private final ThreadPoolExecutor execPool = new ThreadPoolExecutor(
        8, 8, 60, SECONDS, new ArrayBlockingQueue<>(64),
        new ThreadPoolExecutor.AbortPolicy());        // 队列满即拒, 绝不阻塞扫描
    private final Map<String, AtomicBoolean> sourceLocks = new ConcurrentHashMap<>();
    private final Map<String, RateLimiter> limiters = new ConcurrentHashMap<>();
    private final Map<String, AtomicInteger> limiterQps = new ConcurrentHashMap<>(); // 配置热生效

    @PostConstruct
    void init() {
        scanner.setPoolSize(1); scanner.initialize();
        scanner.scheduleAtFixedRate(this::scanAndDispatch, Duration.ofSeconds(30));
    }

    void scanAndDispatch() {
        if (!running.get()) return;
        for (SourceConfig src : sourceConfigService.selectDue(LocalDateTime.now())) {
            AtomicBoolean lock = sourceLocks.computeIfAbsent(src.getSourceCode(), k -> new AtomicBoolean());
            if (!lock.compareAndSet(false, true)) continue;
            try {
                execPool.submit(() -> { try { executeWithGuard(src); } finally { lock.set(false); } });
            } catch (RejectedExecutionException e) {
                lock.set(false);
                Metrics.counter("crawl_task_skipped", "source", src.getSourceCode()).increment();
            }
        }
    }

    void executeWithGuard(SourceConfig src) {
        if (!circuitBreaker.allow(src)) return;                          // 三态熔断
        TaskInstance run = taskService.start(src);                       // 读入 last_cursor
        try {
            RateLimiter rl = limiters.compute(src.getSourceCode(), (k, old) ->
                // 配置变更即重建(旧computeIfAbsent不生效的修复)
                old != null && limiterQps.get(k).get() == src.getRateLimitQps() ? old
                    : { limiterQps.put(k, new AtomicInteger(src.getRateLimitQps()));
                        yield RateLimiter.create(src.getRateLimitQps()); });
            CrawlAdapter adapter = adapterRegistry.get(src.getAdapterKey());
            CrawlResult result = adapter.fetch(src, src.getLastCursor(), rl);
            rawRecordService.batchUpsert(result.records(), run.getId()); // uk: source+outer+date
            List<NormalizedDoc> docs = adapter.parse(src, result.records());
            driftDetector.check(src, docs);                              // P1阻断 / P2P3记日志
            boolean offered = governQueue.offer(docs, 3, SECONDS);       // 限时背压
            if (!offered) rawRecordService.markPending(result.records()); // parse_status=0 待补偿
            sourceConfigService.commitCursor(src.getSourceCode(), result.newCursor()); // 成功才提交
            circuitBreaker.onSuccess(src);
            taskService.finish(run, result.hasPartialFailure() ? 3 : 1, result.recordCount(), null);
        } catch (AntiCrawlException e) {                                 // 403/验证码特征
            circuitBreaker.openImmediately(src);
            alertService.p0("源被反爬: " + src.getSourceCode());
            taskService.finish(run, 2, 0, e.getMessage());
        } catch (Exception e) {
            circuitBreaker.onFailure(src);
            taskService.finish(run, 2, 0, e.getMessage());
        }
    }
}
```

### 1.3 三态熔断器

```java
public class CircuitBreaker {
    boolean allow(SourceConfig src) {
        switch (src.getCircuitState()) {
            case 0: return true;                                         // 闭合
            case 1:                                                      // 开路
                if (now().isAfter(src.getCircuitOpenUntil())) {          // 到期→半开
                    src.setCircuitState(2); sourceConfigService.save(src); return true; // 放行1个探测
                }
                return false;
            case 2: return probePermit.tryAcquire(src);                  // 半开: 恰好1个
        }
    }
    void onSuccess(SourceConfig src) { src.setCircuitState(0); src.setCircuitFailCount(0); save(src); }
    void onFailure(SourceConfig src) {
        int fails = src.getCircuitFailCount() + 1;
        if (src.getCircuitState() == 2 || fails >= 5) {                  // 探测失败或连败5次→开路
            src.setCircuitState(1);
            src.setCircuitOpenUntil(now().plusSeconds(BACKOFF[min(fails/5, 3)])); // 30s/2m/10m/30m
        }
        src.setCircuitFailCount(fails); save(src);
    }
    void openImmediately(SourceConfig src) { /* 403特征: state=1 + 退避 + P0告警 */ }
}
```

## 2. 治理模块（M4）

```java
@Service
public class GovernancePipeline {
    private final BlockingQueue<List<NormalizedDoc>> governQueue = new LinkedBlockingQueue<>(10000);
    private final ExecutorService governPool = Executors.newFixedThreadPool(4);

    public boolean submit(List<NormalizedDoc> docs) throws InterruptedException {
        return governQueue.offer(docs, 3, SECONDS);      // 限时背压: 超时由采集侧记pending
    }

    void consumeLoop() {                                  // 4线程常驻
        while (!Thread.currentThread().isInterrupted()) {
            List<NormalizedDoc> batch = governQueue.poll(5, SECONDS);
            if (batch == null) continue;
            for (NormalizedDoc doc : batch) processOne(doc);
        }
    }

    void processOne(NormalizedDoc doc) {
        retry(3, List.of(1000L, 2000L, 4000L), () -> {   // 单条重试
            cleanWorker.clean(doc);                       // 去HTML/广告词库/繁简/截断5000
            if (dedupWorker.isDuplicate(doc)) { doc.setIsDuplicate(1); persist(doc); return; }
            List<EntityMention> mentions = entityWorker.extract(doc);
            QualityScore q = qualityWorker.evaluate(doc);
            persistInTx(doc, mentions, q);                // 单条事务(禁批级事务)
            if (q.getScore() >= 2) sentimentQueue.offer(doc, 3, SECONDS);
        }, ex -> deadLetterService.save("govern", doc, ex)); // 3次仍败→死信, 继续下一条
    }
}
```

**Dedup 分桶**：
```java
boolean isDuplicate(NormalizedDoc doc) {
    long hash = simHash64(doc.getTitle() + " " + doc.getContent());   // 二元组+murmur3_128
    String bucketKey = "simhash:bucket:" + doc.getSecurityCode() + ":" + (hash >>> 48); // 高16位分桶
    for (String h : redis.smembers(bucketKey))
        if (Long.bitCount(hash ^ Long.parseUnsignedLong(h)) <= 3) return true;
    redis.sadd(bucketKey, String.valueOf(hash));
    redis.expire(bucketKey, 24, HOURS);
    evictOldestBucketIfOverflow(doc.getSecurityCode());   // 超上限按时间桶淘汰最旧, 禁整删
    return false;
}
```

**Entity**：词典 = `m2_security.security_name` ∪ `m2_security_alias`；构建 AC Trie 后双 buffer 原子切换（词典热更）；主标的 = mention 次数最多者，全部实体落 `m4_entity_mention`。

**Quality**：扣分制（字数<10 → -2；广告词 → -3；作者频控 key=`source:authorId` 原子 incr；重复 → -2；高互动 +1），clamp [1,5]。

## 3. 情感模块（M5）

### 3.1 L1 引擎（定稿）

```java
public SentimentResult analyze(String title, String content) {
    // 词典全部来自 m5_sentiment_dict, 六类共Trie, 最长匹配切词
    double titleScore   = scoreText(title);      // 标题
    double contentScore = scoreText(content);    // 正文
    double raw = title != null ? 0.6*titleScore + 0.4*contentScore : contentScore;
    double score = Math.tanh(raw / 3.0);
    String label = score > 0.15 ? "positive" : score < -0.15 ? "negative" : "neutral";
    return SentimentResult.of(score, label, confidence(score, hits), dictVersion, ALGO_VERSION);
}

private double scoreText(String text) {
    double sum = 0; boolean inTransition = false;
    List<Token> tokens = acTrie.maxMatch(text);   // 情感词/否定/程度/转折 同一Trie
    for (int i = 0; i < tokens.size(); i++) {
        Token t = tokens.get(i);
        if (t.isSentenceEnd()) { inTransition = false; continue; }  // 句读复位
        if (t.type == TRANSITION) { inTransition = true; continue; }
        if (t.type != SENTIMENT) continue;
        double s = t.baseScore;
        for (int j = Math.max(0, i-3); j < i; j++) {                // 前3 token窗口
            // 多个否定词按出现次数奇偶翻转（双重否定=肯定，如"不是不看好"）；
            // 标注集回归用例必须显式覆盖双重否定样本，防止口径回退
            if (tokens.get(j).type == NEGATION) s = -s;
            if (tokens.get(j).type == DEGREE)   s *= tokens.get(j).weight;
        }
        if (inTransition) s *= 1.5;
        sum += s;
        detail.add(WordDetail.of(t, s));
    }
    return sum;
}
```

### 3.2 情绪指数（最终公式 + 实现）

```
Si = 50 + 50 × Σ(wk_eff × score_k) / Σ(wk_eff)          # [0,100]

wk_eff = w_account × w_time × w_source × w_quality × w_interaction × conf_factor
  w_account     = max(0.1, kol_score/100)     # V1恒0.1, 作者画像启动全量load内存Map, 30min刷新
  w_time        = clamp(0.5^(Δt/24h), 0.05, 1.0)  # Δt=收盘时刻-发布时间; 盘后帖Δt=0
  w_source      = m3_source_config 可配 (东财1.0/雪球0.9/同花顺0.9)
  w_quality     = quality_score / 5
  w_interaction = clamp(ln(1+互动数), 0.5, 3.0)
  conf_factor   = 0.3(零命中) | 0.6(confidence<0.3) | 1.0

空值三态: post_count=0 → NULL("—"); sample_post_count=0 → NULL("暂无有效信号"); 否则计算值
signal_level: NO_DATA / LOW_SAMPLE(sample<10) / HIGH_VOLATILE(5日σ>20或日环比>30) / NORMAL
confidence = clamp((1-e^(-sample/30)) × (1-min(1,σ_score/0.8)), 0.05, 0.95)  # 仅展示与告警门槛
板块聚合: SELECT DISTINCT doc_id 去重后加权
调度: 15min滚动(交易日盘中) + 日频终值(交易日17:00, 过交易日历) + 重放联动重算
落库: m5_sentiment_index(uk scope+date) 带 dict_version + algo_version → 同版本重算可复现
```

## 5. 应用与前端

- **详情页聚合**：`CompletableFuture` 七卡并行（每卡超时 500ms，总预算 700ms）；Redis 缓存 5min±10% 抖动 + 空值缓存 1min + 回源每 key 每秒 ≤1 次
- **前端**：Vue3+TS+Element Plus+ECharts+Pinia；颜色全走 CSS 变量；情绪双轴图右轴 [0,100] markLine 70/50/30；WS 单例 + msgId 跳号重连 + 3 次失败降级 10s 轮询
- **后台**：数据源看板（含五源健康度/字段缺失率）+ 词典管理（CSV 导入预览 + 版本快照 + 回滚入口）+ 质量五卡
- **审计**：ADMIN 写操作 AOP 切面 → `sys_audit_log`（biz_id 串联）

## 6. 无外键下的一致性保障

| 风险 | 机制 |
|---|---|
| 孤儿 mention/result（doc 删除后残留） | 淘汰任务按 created_at 同步清理（04:00 批删） |
| 引用不存在的 code（自选股加了退市股） | 应用层校验 + 每日对账任务扫描报孤儿率 |
| 重放覆盖顺序 | UPSERT 幂等键兜底； replayed_at 标记 |
| 对账 | 每日 02:00 四层对账（采集=治理产出+去重+丢弃+死信），diff>0.1% 告警 |
