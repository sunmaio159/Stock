## 4. 个股详情页七卡片（V1.3 增强）

### 情绪指数展示规范（V1.3 新增，C-03）

**产品定位声明**（所有展示情绪指数的位置必须遵循）：

> 情绪指数是基于公开舆情文本的统计参考信号，不是投资建议，不构成任何买入/卖出结论。

**三条硬性约束**：
1. 情绪指数**永不单独给出方向性结论**，所有展示位必须同时给出**时间窗口**与**近期基准**（如"近 5 日均值"）
2. 禁止出现"推荐""必涨""抄底""逃顶"等措辞；告警文案只能是**事实描述**（"声量较上一交易日同期增长 3.2 倍"）
3. 页脚与详情页固定展示免责声明，**不可关闭、不可折叠**

**signalLevel 展示规范**：

| signalLevel | 含义 | 触发条件 | UI 展示 |
|---|---|---|---|
| `HOT` | 偏热 | sentimentIndex ≥ 70 | 红色温度计 + "偏热（情绪高涨）" |
| `COLD` | 偏冷 | sentimentIndex ≤ 30 | 绿色温度计 + "偏冷（情绪低迷）" |
| `NORMAL` | 正常 | 30 < sentimentIndex < 70 | 灰色温度计 + "正常" |
| `NO_SIGNAL` | 无有效信号 | samplePostCount = 0 | 灰色"—" + "暂无有效情绪信号" |
| `NO_DATA` | 无数据 | postCount = 0 | "—"（无数据）|

### 行情降级展示（V1.3 新增，A-01）

当 `priceStale=true` 或 `X-Degraded: quote` 时：
- 价格数字颜色变灰 + 右侧小标签"延时行情"
- 详情页速览卡顶部横幅："实时行情暂不可用，显示最近收盘价"
- WS 推送的 `stale=true` 时，前端停止闪烁动画

### ECharts 要点（不变）

双轴图右轴 [0,100]；K 线阳线红阴线绿；`dataZoom` 内嵌+滑块。
