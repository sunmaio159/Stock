## 1. 测试策略

**金字塔**：单测 60%（JUnit5+Mockito / Vitest）→ 集成 25%（Testcontainers 真实 MySQL/Redis + API 契约测试）→ E2E 15%（Playwright 关键路径：登录→工作台→详情→告警处理）。
