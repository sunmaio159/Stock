## 2. 视觉规范（Design Token）

**A 股配色（默认，可切换国际色）**：涨 `#F5495B` / 跌 `#00A870` / 平 `#909399`；品牌 `#2B6CF6`；告警 P0 `#F5495B` / P1 `#FF9F1C` / P2 `#4DA3FF`。
**暗色模式**：背景 `#1A1D24`/`#22262E`/卡片 `#2A2E36`；文字 `#E5EAF0`/`#A0A6AD`；涨跌色暗色提亮 `#FF5A6E`/`#26C281`。
**字体**：正文 `'Inter','PingFang SC','Microsoft YaHei'`；数字 `'DIN Alternate','Roboto Mono',monospace`；Body 14px/22px，Number-L 24px/32px/700。
**间距**：4px 基准（4/8/12/16/24/32/48）；卡片圆角 8px，阴影 `0 2px 8px rgba(0,0,0,.06)`。
**所有颜色必须走 CSS 变量**（`--color-up` 等），禁止组件内硬编码——支持国际色反转与暗色（修订前端勘误 F3）。

## 3. 工作台五卡片（V1）

布局：12 栏栅格，max-width 1440px，卡片间距 16px。
1. **自选股情绪红黑榜**（7 栏×2 行）：红榜/黑榜 Top5，字段=代码/名称/情绪指数(🔥≥70 / 常温 30-69 / ❄<30，**[0,100] 量纲**，null 显示"—")/涨跌幅/热度分位；点击进详情页
2. **大盘速览**（5 栏）：三大指数、涨跌家数、北向（V2）、**市场情绪温度计**（全市场指数均值）
3. **待办告警**（5 栏）：P0>P1>P2 → 时间倒序；[处理] 标记 ack
4. **今日热帖 Top10**（12 栏）：标题(40字截断)/来源/情绪标签/互动数/标的标签；点击右侧抽屉看摘录+原文链接
5. **持仓关注异动**（12 栏横排）：每标的一卡：突增🔥/反转⚡(V2)/价格📉/正常✓

数据：`GET /api/workbench` 一次聚合 + WS 增量推送。

## 4. 个股详情页七卡片

布局：固定头部（56px：代码/名称/价/涨跌/加自选）+ Tab 栏（48px sticky）+ 内容区；Tab 与 `?tab=` 同步；**首屏仅请求 `cards=overview,sentiment`**，其余 Tab 激活时按需加载。

| 卡片 | V1 内容 | V2+ |
|---|---|---|
| 1 速览 | 实时价格块、情绪温度计（0-100，含近 5 日均值）、热度分位条 | 综合评分雷达（V3） |
| 2 舆情 | **情绪走势叠加 K 线双轴图**（右轴 0-100，markLine 70/50/30；V1 无日K 数据时只画情绪折线）、词云、Top 热帖（正/负/中筛选） | 话题聚类 |
| 3 技术面 | 占位 `available:false` → 敬请期待 | 日K+MA/MACD/KDJ/RSI/BOLL+关键价位 |
| 4 资金面 | 占位 | 主力流向柱/龙虎榜/北向/两融 |
| 5 基本面 | 占位 | 8 期趋势/杜邦拆解/行业排名 |
| 6 机构观点 | 占位 | 评级分布/目标价/研报列表 |
| 7 风险 | isSt + 退市状态 + 该股近期告警事件 | 商誉/质押/减持/问询/诉讼 |

ECharts 要点：双轴图配置以 `05 §5.6` 修订为准；K 线阳线红 `#F5495B` 阴线绿 `#00A870`；`dataZoom` 内嵌+滑块双形态。

## 5. 告警中心（V1 简化 → V2 完整）

V1 表单：名称 / priority 单选（P0/P1/P2）/ scope（自选股/单标的）/ 指标+运算符+阈值（下拉白名单，见 04 §7）/ 冷却 / 日上限 / 渠道（企微+站内）/ 夜间勿扰开关。DSL 预览只读。
V2：条件树嵌套编辑器（AND/OR）、规则回测按钮、dingtalk/email、订阅管理页。
事件列表：筛选（状态/优先级/类型/日期）+ 批量处理 + 导出；详情抽屉含触发值、降噪信息（合并次数/今日已触发/下次最早触发）、溯源帖列表。

## 6. 运营后台（V1 两页）

- **数据源看板**：全局健康度（成功率/P95/活跃源）+ 源级表（成功率/P95/新增每小时/连续零新增/字段缺失率/熔断状态）+ 24h 新增趋势 + 重放入口
- **词典管理**：四词库 Tab（情感/否定/程度/广告）+ 搜索 + 增删改 + CSV 批量导入（预览：新增/跳过）+ 导入后自动重建 AC 自动机

## 7. 多端适配（V2 实施，V1 只预留）

断点：XL≥1440 / LG 1200-1439 / MD 768-1199 / SM<768（单栏+底部 Tab）。
触控：点击区 ≥44px；长按替代右键；K 线双指缩放单指平移；详情页移动端默认仅速览卡、七卡横向滑动卡片栈。
**V1 要求**：组件不写死像素宽度（用栅格/%），不引入 hover-only 交互——为 V2 适配减债。
