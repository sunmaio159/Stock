# 01 需求与范围基线（定稿）

> 来源：分册 A 阶段1 + 整理版，经评审修订（V1 范围三版合一）。本文档是范围争议的唯一仲裁依据。

## 一、用户画像（三类）

| 画像 | 特征 | 核心诉求 | 付费意愿 |
|---|---|---|---|
| 个人投资者（散户进阶） | 3-10 年经验，10-200 万持仓，手机+PC | 信息过载筛选、情绪面信号、简洁告警 | 30-100 元/月 |
| 小型投研团队（3-8 人） | 私募/工作室，有分工 | 多源汇聚、情绪信号可追溯、团队协作、可导出 | 500-3000 元/月 |
| 量化爱好者 | 会编程，自建策略回测 | 结构化 API、情绪因子、Webhook、历史可回溯 | 按量付费 |

> **V1 实际服务对象**：个人自用/小团队内部（注册 ≤100，DAU ≤30）。压测与容量按 50 并发设计；200 并发、对外开放是 V2+ 指标。

## 二、核心使用场景（六个）

1. **盘前情报速览**（07:00-09:15）：自选股隔夜舆情 + 情绪指数变化 + 突增告警
2. **盘中实时监控**（09:30-15:00）：行情快照 3-5s 推送 + 突增告警 + 详情页快速查看（P95≤800ms）
3. **盘后复盘**（15:00-18:00）：当日表现总览 + 舆情时间线 + 资金流向
4. **智能选股**：技术+基本+情绪+资金四维组合筛选（V2）
5. **舆情深度跟踪**：情绪趋势 + 词云 + KOL 观点 + 板块对比
6. **告警配置与接收**：可视化规则 + 降噪 + 企微/站内触达

## 三、痛点与竞品空白（摘要）

痛点四维度：技术面（口径不一致、数据割裂）、使用面（信息过载、自选股分散、告警轰炸）、基本面（更新延迟、缺行业分位）、数据面（另类数据难获取、字段不稳、历史难回溯）。

竞品空白 = Aquila 差异化：**舆情情绪指数、突增检测告警、含情绪的四维选股、可解释评分卡、水军过滤**——东财/同花顺/雪球均无。

## 五、V1 范围基线（6 周 MVP，唯一版本）

| # | 交付物 | 验收标准 |
|:-:|---|---|
| 1 | 登录（手机号+验证码，JWT AT 2h/RT 7d） | API 契约通过，错误码正确 |
| 2 | 工作台五卡片（红黑榜/热帖/异动/大盘/待办告警） | 真实数据渲染 ≤1.5s |
| 3 | 自选股（≤20 组 ×100 只，排序/备注/跨端同步） | CRUD + WS 同步正常 |
| 4 | 证券主数据（沪深 A 股全量含 ST）+ 行业归属 + 交易日历 | ≥5400 标的，行业覆盖 ≥98% |
| 5 | 标的搜索（代码/名称/拼音） | P95 ≤200ms |
| 6 | 舆情三源采集（5-15min 增量） | 72h 成功率 ≥99%，日帖量 ≥5 万 |
| 7 | 治理流水线四 Worker | 端到端 P95 ≤30s；去重召回 ≥90% |
| 8 | L1 情感引擎（词典入库可后台维护） | 500 条标注集准确率 ≥75% |
| 9 | 情绪指数（日频 + 15min 派生） | 每交易日 18:00 前完成 |
| 10 | 个股详情页（速览+舆情真实，五卡占位 `available:false`） | 首屏 P95 ≤800ms |
| 11 | WebSocket（行情快照 + 告警推送） | 断线重连正常 |
| 12 | 基础告警（价格 + 声量环比 + 15min 合并降噪，企微+站内） | 触发到触达 ≤30s |
| 13 | 数据质量（漂移检测/幂等/30 天重放） | 重放演练通过 |
| 14 | 运营后台骨架（数据源看板 + 词典维护） | 可用 |

**V1 明确不做**：L2 模型、Z-Score/情绪反转（但 V1 的 15min 派生表为其积累基线数据）、技术/资金/基本面卡片、选股器、评分卡、DSL 编辑器、移动端、RSS/公告/研报/行情日K 采集。
