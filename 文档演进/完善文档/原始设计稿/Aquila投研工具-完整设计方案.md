## 四、核心设计决策速览

### 4.1 务实化技术选型（V1）

| 层 | 选型 | 替代（暂缓） | 理由 |
|:---|:----|:----|:----|
| 前端 | Vue 3 + Element Plus + ECharts 5 | — | 组件丰富，图表能力强 |
| 后端 | Spring Boot 3 + Java 17 + MyBatis | — | 成熟稳定，生态完整 |
| 数据库 | MySQL 8 | CK（V4） | 单机够用，运维简单 |
| 缓存 | Redis (Lettuce) | — | 热榜/限流/会话 |
| 调度 | ThreadPoolTaskScheduler(8) | PowerJob | 无需额外部署 |
| 消息 | 同步 Service 调用 | Kafka | 无需额外中间件 |
| 原始存储 | crawl_raw_record 表 | MinIO | 30 天保留，DB 内闭环 |
| 搜索 | MySQL LIKE + 前缀索引 | ES | 降级够用 |
| 情感引擎 | L1 规则引擎 | FinBERT(L2)/LLM(L3) | 成本~0，起步够用 |
| 向量库 | 砍 | Milvus | V3 有 RAG 再引入 |

### 4.2 四条流水线

1. **采集流水线**：调度器 → Adapter → RawRecord → Parse → Schema 校验 → NormalizedDoc
2. **治理流水线**：Clean → Dedup(SimHash64) → Entity(AC自动机) → Quality → Index
3. **情感流水线**：BudgetRouter → L1 规则 → ana_sentiment_result → 日级/15min 派生表 → 突增检测
4. **投研流水线**：情感 + 行情/资金/财报 → 因子计算 → 评分卡(5维加权) → 告警引擎 → 多渠道触达

### 4.3 综合评分卡公式

```
CompositeScore = 0.25×基本面 + 0.20×估值 + 0.20×资金面 + 0.20×技术面 + 0.15×舆情情绪
```
- 因子定义表化存 DB（`ana_factor_def`），后台调权重无需发版
- z-score 标准化后加权，输出 0~100 + 归因条形图
- 得分持久化快照，支持"当时的评分 vs 现在"对比

### 4.4 情绪指数公式

```
Si = 100 × Σ(wk × score_k) / Σ(wk)
wk = w_account × w_time(半衰期24h,衰减0.5) × w_source × w_quality × log(1+互动数)
```

### 4.5 版本演进路线

| 阶段 | 周期 | 交付模块 |
|:----:|:----:|:--------|
| V1 MVP | 6 周 | M1+M2+M3(3源)+M4(轻)+M5(L1)+个股详情页 |

## 五、最终方案总结

### 一句话定位
**Aquila 是一套面向个人投资者/小团队的 A 股投研工具，以"采集→治理→情感→投研"四条流水线为骨架，提供一屏式个股研报视图和智能告警触达。**

### 核心价值主张
1. **舆情先行**：散客情绪（股吧/雪球）5-15 分钟增量采集，L1 规则引擎实时标注，情绪指数可解释
2. **一屏式研报**：个股详情页七卡片聚合，技术/资金/基本面/舆情/机构/风险一屏掌握
3. **智能告警**：DSL 规则引擎 + 三模型突增检测 + 降噪合并，P0 异动即时触达

### 技术架构亮点
1. 务实化轻量栈：MySQL+Redis+SpringBoot 单体，无 Kafka/CK/Milvus 依赖
2. 插件化 Adapter 采集：源级隔离，主链路无硬编码，新增数据源只需实现接口
3. SimHash64 + AC 自动机：轻量治理（去重+实体抽取），Java 可实现
4. 三级情感引擎 + BudgetRouter：成本可控的分级处理
5. 因子表化 + 评分快照：后台调权重不发版，支持历史对比避免幸存者偏差

### 差异化优势
1. vs 东方财富：插件化采集 + 情绪量化指数 + 一屏式研报（非碎片化数据）
2. vs 同花顺：散客舆情深度治理（SimHash 去重+KOL 评分+突增检测）
3. vs 雪球：DSL 告警引擎 + 多渠道触达（企微/钉钉/WebPush）
4. vs 通用量化平台：情感维度融入评分卡（15% 权重），非纯技术面
5. vs 财经媒体：Raw Lake 30 天重放 + 字段漂移检测，数据可追溯

### 预期成果指标
- 热帖发布到可见：P95 ≤ 3 min（核心源 ≤ 90 s）
- 个股详情页首屏：P95 ≤ 800 ms
- 采集任务成功率：≥ 99%
- 日频因子与评分：每交易日 18:00 前完成
- 系统可用性：99.5%
- V1 MVP 年度成本：约 ¥18,790
